Framework Overview

一条链路，六个判断点

讨论不是一个动作，而是一条有先后顺序的链路。前面任何一步没有对齐，后面的所有推理都建立在不同的基础上。 点击任意节点，查看这一步到底在解决什么。

Five Baselines

五大基线

基线本身不随场景改变，改变的是对它的要求精度。五张卡片分别对应：统一对象、统一评价函数、 验证事实、保证推理、评估收益。点击卡片展开完整说明。

Discussion Flow

讨论流程

左侧是一次讨论的检查顺序，右侧是每一步的含义与两条分支的走向。点击左侧任意一步查看细节。

Tolerance

讨论宽容度

不同场景不需要不同规则，只需要不同的精度要求。拖动滑块，观察四项基线的要求如何随场景变化。

Cognitive Gain

讨论最大的价值，不一定是得到答案，
而是增加认知。

把衡量标准从「对方是否被说服」换成「是否有人获得了新认知」，讨论就从零和的输赢变成了可积累的产出。

    高质量讨论未必产生共识，但一定产生认知增量。

    Consensus is optional · Cognitive gain is not
    When To Stop

    是否退出讨论

    退出讨论是一个可以判断的技术问题，而不是情绪问题。依次回答三个问题，看它把你带到哪里。
