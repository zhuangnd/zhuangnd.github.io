Framework Overview

一条链路，六个判断点

讨论不是一次性表达观点，而是一串有先后顺序的检查。前一步不成立，后一步就失去意义。 点击任意节点，查看它在链路中的位置、要回答的问题，以及失败后会发生什么。

The Five Baselines

五大基线

每一条基线对应一类错误：概念定义防偷换概念，标准约束防评价体系错位， 事实依据防前提失真，逻辑遵循防推理跳步，认知增量防无效消耗。 点击卡片展开完整说明，卡片底部会实时显示你在右侧选定的精度等级下的要求。

Discussion Precision

精度等级：基线不变，宽容度可变

不同场景不是采用不同规则，而是采用不同的精度要求。 越往右，概念越不能模糊、标准越不能隐含、事实越不能凭印象、推理越不能跳步。 拖动滑块，页面上与该要求相关的位置会同步变化。

Discussion Radar

讨论雷达：五个维度一眼看懂

把一场讨论的五个维度画在同一张图上。 形状越接近外圈、越接近正五边形，讨论质量越高；某一角塌陷，就能立刻定位问题出在哪一层。

Cognitive Gain

认知增量：讨论真正的收益

讨论最大的价值，不一定是得到答案，而是增加认知。

什么算认知增量

新的认知不等于改变立场。下面任意一条成立，这场讨论就已经有收益了。

高质量讨论未必产生共识，但一定产生认知增量。

Exit Decision

是否退出讨论：一个决策树

日常讨论往往无法判定谁对谁错，但可以判定是否还有继续的价值。 按顺序回答三个问题，只要有一个是 YES，就还有讨论空间。

退出讨论 = 认输 ≠ 退出讨论 = 没有新的认知增量
