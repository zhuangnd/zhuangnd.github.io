# DQF · 理论框架说明

> 本文件说明框架的**内容逻辑**：五条基线是什么、为什么是这五条、
> 它们之间什么关系、以及为什么用「认知增量」而不是「说服」作为衡量标准。
> 实现细节见 `interaction.md`。

---

## 一、框架的由来

起点是三条基线：

```
概念定义 → 标准约束 → 逻辑遵循
```

它们分别对应三个不同层面的错误：

| 基线 | 防止的问题 |
|------|-----------|
| 概念定义 | 偷换概念、语义混乱 |
| 标准约束 | 双方评价体系不同 |
| 逻辑遵循 | 推理错误、结论错误 |

**但三条不完整。** 即使定义一致、标准一致、逻辑正确，只要事实本身是错的，
结论依然会错——逻辑只能保证「前提为真则结论成立」，它不能保证前提为真。
因此补上第四条：

```
① 概念定义（讨论什么）
      ↓
② 标准约束（如何评价）
      ↓
③ 事实依据（事实是否真实）
      ↓
④ 逻辑遵循（推理是否有效）
      ↓
   结论
```

**第五条是收益评估层。** 前四条都是"正确性"检查，但一场讨论值不值得继续，
取决于它有没有产生新的认知。于是框架收束为：

```
① 概念定义 → ② 标准约束 → ③ 事实依据 → ④ 逻辑遵循 → ⑤ 认知增量 → ⑥ 是否值得继续
```

对应的通用认知问题：**对象（Object）→ 标准（Criterion）→ 事实（Evidence）→ 推理（Reasoning）→ 收益（Gain）**。

---

## 二、五条基线

### 2.1 概念定义 · Concept

**本质：确定讨论对象。**

> 很多争论其实不是观点不同，而是讨论的对象不同。

例："AI 会取代程序员"——至少需要定义：

- AI 指什么（LLM？Agent？AGI？）
- 取代是什么意思（全部失业？岗位减少？工作方式改变？）
- 程序员的范围（初级？高级？全部？）

**常见错误**：偷换概念、语义漂移（中途悄悄改变词的含义）、
把多义词当单义词、用比喻或举例代替定义。

**触发信号**：出现抽象名词（文明、自由、公平、效率、成功），且双方都没说明它指什么。

---

### 2.2 标准约束 · Standard

**本质：确定评价函数。**

> 不是事实冲突，而是评价函数不同。

NBA 历史最佳之争是典型：

- 一组人按 MVP、冠军、累积数据
- 另一组人按技术天花板、巅峰高度、比赛影响力

**双方都可能正确。** 没有共同的评价函数，就不存在统一结论。

**常见错误**：隐含标准、中途换标准、用结果反推标准、双重标准、
把"综合评价"当成无需说明的免责声明。

**触发信号**：出现比较级或最高级（更好、最强、第一、伟大）。

---

### 2.3 事实依据 · Evidence

**本质：保证前提真实。**

> 定义正确 + 标准正确 + 逻辑正确 + 数据造假 = 结论依然错误。

因此事实必须作为**独立的一层**，而不是隐含在逻辑之中。

**常见错误**：以个人经历代替样本、幸存者偏差、把相关当因果、
引用无从核实的"研究表明""网上都说"、把感受当数据。

**触发信号**：有人用"我觉得"支撑一个**事实判断**（而非价值判断）。

---

### 2.4 逻辑遵循 · Logic

**本质：保证推理有效。**

例："中国 GDP 增长，所以每个人都更富有"——中间每一步都需要证明：

```
GDP 增长
   ↓  这一步需要证明
收入增长
   ↓  这一步需要证明
居民收入增长
   ↓  这一步需要证明
所有居民都更富有
```

**常见错误**：跳步、偷换命题、循环论证、把相关当因果、以人为据、诉诸多数、假两难、滑坡推论。

**触发信号**：出现"所以""可见""由此可见"等结论连接词。

---

### 2.5 认知增量 · Cognitive Gain

**本质：评估讨论的收益。**

它把讨论目标从**说服（Persuasion）**转向**增加认知**：

| | 说服 | 认知增量 |
|---|------|---------|
| 判断标准 | 对方是否改变观点 | 是否有人获得了新的认知 |
| 风险 | 容易变成输赢、话术比拼、情绪化 | — |
| 性质 | 零和 | 可累积 |

**"新的认知"不等于改变立场**，它包括：

1. 学到了新的事实
2. 发现自己的概念定义不够准确
3. 意识到存在另一种评价标准
4. 找到了自己推理中的漏洞
5. 明确了这个问题目前无法下结论
6. 发现真正的分歧点在哪里

**高质量讨论的定义**：不是双方意见一致，而是讨论结束后双方都能准确表述——

1. 我自己的观点是什么
2. 对方的观点是什么
3. 双方真正的分歧在哪里
4. 为什么目前无法统一

**最重要的推论**：讨论最大的价值，不一定是得到答案，而是**缩小问题**。
"AI 到底好不好？" → "我们真正分歧的是效率优先还是就业优先"——
虽然没有统一观点，但问题被缩小了。这就是认知增量。

## 三、精度模型：基线不变，宽容度可变

不同场景**不是采用不同规则，而是采用不同的精度要求**。
基线本身恒定，变化的是允许偏离基线的程度。

| 档位 | 概念定义 | 标准约束 | 事实依据 | 逻辑遵循 | 误差容忍 | 讨论成本 |
|------|---------|---------|---------|---------|---------|---------|
| 闲聊 | ★★☆☆☆ | ★★☆☆☆ | ★☆☆☆☆ | ★★☆☆☆ | 88% | 极低 |
| 一般交流 | ★★☆☆☆ | ★★★☆☆ | ★☆☆☆☆ | ★★☆☆☆ | 62% | 低 |
| 工作决策 | ★★★☆☆ | ★★★☆☆ | ★★☆☆☆ | ★★★☆☆ | 42% | 中 |
| 技术评审 | ★★★★☆ | ★★★★☆ | ★★★☆☆ | ★★★★☆ | 26% | 高 |
| 学术研究 | ★★★★★ | ★★★★★ | ★★★★★ | ★★★★★ | 14% | 很高 |
| 法律裁判 | ★★★★★ | ★★★★★ | ★★★★★ | ★★★★★ | 6% | 极高 |
| 数学证明 | ★★★★★ | ★★★★★ | ★★★★★ | ★★★★★ | 1% | 最高 |

每一档在四个维度上的具体要求：

| 档位 | 概念定义 | 标准约束 | 事实依据 | 逻辑遵循 |
|------|---------|---------|---------|---------|
| 闲聊 | 大致理解一致即可 | 默认社会共识 | 个人感受与印象即可 | 允许直觉跳跃 |
| 一般交流 | 遇明显歧义再澄清 | 出现分歧时再议 | 可凭经验、常识、身边案例 | 允许略去中间推导 |
| 工作决策 | 关键术语当场确认 | 重要判断需说明依据 | 关键数字必须能说清来源 | 关键结论需给出理由 |
| 技术评审 | 核心概念明确定义 | 明确指标与适用范围 | 引用数据并说明样本来源 | 完整推导，说明成立条件 |
| 学术研究 | 可操作定义 + 适用边界 | 指标、权重与选择理由 | 可验证、可复现、说明统计方法 | 逐步论证，主动检查反例 |
| 法律裁判 | 成文、可援引、不依赖语境 | 成文、可援引、可复核 | 完整证据链，注明偏差与局限 | 不得跳步，须排除替代解释 |
| 数学证明 | 形式化定义，边界完全确定 | 评价函数预先固定，不可变更 | 仅接受公理与已证命题 | 每步须由既定规则严格导出 |

**两条核心原则：**

1. **日常讨论追求可理解，学术讨论追求可定义。**
2. **讨论越重要、结论影响越大、可逆性越低，越应提高精度要求；**
   **讨论越偏向交流与启发，越可适当放宽，但不能完全放弃基线。**

## 四、退出讨论判断

日常讨论往往**无法判定结论对错，但可以判定是否还有继续的价值**。
这是两个不同的问题。

### 4.1 为什么日常讨论经常定不了对错

以"直播带货"为例，可能存在四种情况：

| 情况 | 分歧层 | 能否继续 |
|------|--------|---------|
| 概念没统一（A 说渠道效率，B 说主播诱导） | 概念层 | 先定义，可继续 |
| 评价标准不同（A 看销量，B 看消费者权益） | 标准层 | 先协商，可继续 |
| 价值观不同（A 重商业效率，B 重消费者权益） | 价值排序 | **逻辑不能证明哪种价值观绝对正确** |
| 事实依据不足（双方都在"我觉得"） | 事实层 | 补证据，或停止 |

### 4.2 决策树

```
还有新事实？
   ├─ YES → 继续讨论（等待或寻找更多证据）
   └─ NO ↓
还能统一概念？
   ├─ YES → 继续讨论（先把对象重新对齐）
   └─ NO ↓
还能统一标准？
   ├─ YES → 继续讨论（先说清按什么判断）
   └─ NO → 停止讨论
```

任一问题答 YES，讨论就还有空间。三个全 NO，继续的边际收益已接近零。

### 4.3 退出 ≠ 认输

> **退出讨论 ≠ 认输 = 没有新的认知增量**

这不是消极行为，而是一次**理性的资源分配决策**。
判断标准不是"我说服对方了吗"，而是"这场讨论有没有增加任何人的认知"。

## 五、诊断器评分规则

诊断器**不是 AI 判断**，而是一套透明、可逐条核对的规则。
每个维度的得分都由信号词命中驱动，命中的词会原样列出，供用户核对是否误判。

### 5.1 概念定义

| 信号 | 权重 |
|------|------|
| 命中定义信号（指的是 / 定义为 / 所谓 / 换句话说 / 狭义 / 口径 …） | 每个 +1.0，上限 +3.0 |
| 命中未定义抽象词（文明 / 自由 / 公平 / 效率 / 割韭菜 …） | 每处 −0.62，上限 −6 处 |
| 基线分 | 3.2 |
| 无任何命中 | 3.8（不涉及抽象概念，不构成障碍） |

### 5.2 标准约束

| 信号 | 权重 |
|------|------|
| 命中显式标准（标准是 / 按…来看 / 指标 / 权重 / 从…角度 …） | 每个 +1.1，上限 +3.0 |
| 命中比较词（更 / 最 / 不如 / 第一 / 历史最佳 …） | 每处 −0.5，上限 −5 处 |
| **有比较却无标准说明** | **额外 −1.2（重罚）** |
| 基线分 | 3.0 |
| 无任何命中 | 3.6 |

> 重罚项的理由：这正是最常见的讨论失分项——双方都在比较，但谁也没说按什么比。

### 5.3 事实依据

| 信号 | 权重 |
|------|------|
| 命中事实支撑（数据 / 统计 / 调查 / 样本 / 来源 / 研究 / % …） | 每处 +0.85，上限 +4 处 |
| 命中主观表述（我觉得 / 肯定 / 显然 / 众所周知 / 网上都说 / 我朋友 …） | 每处 −0.72，上限 −6 处 |
| 基线分 | 3.0 |
| 两者皆无 | 2.6（事实层是空的） |

### 5.4 逻辑遵循

| 信号 | 权重 |
|------|------|
| 命中推理连接词（因为 / 所以 / 因此 / 由此可见 / 意味着 …） | 每个 +0.6，上限 +4 个 |
| 命中风险信号（所有…都 / 一定 / 绝对 / 傻 / 无脑 / 本来就是这样 / 杠精 …） | 每处 −0.95，上限 −5 处 |
| 长文本（>60 字）却无任何连接词 | 额外 −0.6（疑似跳步） |
| 基线分 | 3.6 |

### 5.5 认知增量

| 信号 | 权重 |
|------|------|
| 命中增量信号（原来 / 没想到 / 这么说 / 你的意思是 / 我之前以为 / 分歧在于 …） | 每处 +1.15，上限 +4 处 |
| 命中重复信号（反正就是 / 说到底还是 / 不用说了 / 没法聊 / 无语 …） | 每处 −1.0，上限 −4 处 |
| 基线分 | 2.0（认知增量不会凭空产生） |

### 5.6 综合判定

取五维平均值 `avg`：

| 区间 | 判定 | 说明 |
|------|------|------|
| ≥ 4.0 | **继续讨论** | 五维均衡饱满，正在稳定产生认知 |
| 3.0 – 3.9 | **修复后再谈** | 整体可用，但存在明显短板，先补最低分项 |
| 2.0 – 2.9 | **先补基础** | 基础层未立住，此时谈结论为时过早 |
| < 2.0 | **退出讨论** | 多维度同时塌陷，边际收益接近零 |
| 文本 < 8 字 | 文本过短 | 无法做出有意义的判断 |

## 六、框架的自我引用

这套框架本身也是在讨论中演化出来的：

```
1. 三大基线：概念定义 → 标准约束 → 逻辑遵循
      ↓
2. 补充事实依据：逻辑管不了前提真假
      ↓
3. 提出认知增量：把讨论目标从说服转向学习
      ↓
4. 增加退出判断：把"是否继续讨论"纳入决策
```

这与框架的主题是一致的：**好的框架本身也是认知增量的产物**。
每次使用这套框架分析问题，产出的澄清、边界与漏洞都会沉淀为下一次分析的输入。

---

## 七、一句话总结

> **高质量讨论未必产生共识，但一定产生认知增量。**
>
> 讨论的目的不是赢，而是理解 → 分析 → 增加认知 → 在无法增加认知时适时结束。
